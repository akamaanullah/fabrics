Noor Fabrics - sample website (HTML + CSS + vanilla JS)
Open index.html in any browser (double-click). No build step, no server needed.
- All product data lives in the PRODUCTS array at the top of main.js.
- Cart and wishlist are stored in the browser (localStorage).
- Forms (checkout, custom order, contact, newsletter) validate and show a success message but send nothing.
- Fonts load from Google Fonts (needs internet; falls back to Georgia/Arial offline).
- Photos are free-to-use stock images; see About page > Photo Credits.
